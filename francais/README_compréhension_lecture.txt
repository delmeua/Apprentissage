COMPRÉHENSION DE LECTURE — VERSION FRANÇAISE

Fichiers :
- compréhension_lecture.html : jeu de lecture
- questions.html : gestion des exercices
- questions.js : banque de départ
- README.txt : ce fichier

Les quatre fichiers doivent rester dans le même dossier. Le bouton Quitter revient vers ../index.html.

Le jeu est en français uniquement. L'enfant répond en touchant/cliquant sur une réponse, sans clavier. Le jeu lit les histoires, les questions et les retours à voix haute ; les emojis sont affichés mais pas prononcés.

Voix :
1. StreamElements / voix Celine (français)
2. Google Translate TTS (repli)
3. Synthèse vocale locale du navigateur (dernier recours)

Ces services en ligne ne sont pas garantis et nécessitent une connexion Internet. Certains réseaux ou navigateurs peuvent les bloquer. Le navigateur peut aussi exiger un premier clic avant la lecture audio. Le jeu essaie les fournisseurs l'un après l'autre pour éviter les doubles lectures.

Gestion des exercices :
Ouvrez questions.html pour modifier les histoires, questions, réponses, indices et explications, ajouter ou retirer des exercices. Cliquez sur Enregistrer pour chaque exercice. Les changements sont stockés dans le navigateur utilisé ; ils ne se synchronisent pas automatiquement entre appareils ou navigateurs. Vous pouvez exporter/importer la banque en JSON.

Pour conserver les changements, gardez les fichiers dans le même emplacement et ouvrez les pages depuis le même site ou la même origine. Le stockage local peut être différent selon la façon dont les fichiers sont ouverts (file:// ou serveur web).

Consignes orales : sur la page d'accueil, le bouton « Répéter les consignes » relit les instructions. Au début de chaque question, l'histoire et la question sont lues à voix haute. Le bouton « Réécouter » dans le retour permet de relire le dernier commentaire oral.
